# FlowLedger 投记 · 个人投资记账

**个人全渠道投资出入金管理工具** — 记录每一笔资金流动，追踪真实盈亏，分析你的投入行为模式，在 FOMO 冲动时给你一个冷静提醒。单文件部署，无需后端，数据存本地，开箱即用。

## 为什么做这个？

投资的人或多或少都经历过这样的循环：**亏了 → 不甘心 → 再充钱 → 又亏了 → 继续充**。

很多人到最后都不知道自己到底往里面扔了多少钱，只有一个模糊的感觉："好像亏了不少"。而这种模糊感恰恰是最危险的——因为你不知道具体数字，就不会真正警觉。

FlowLedger 就是为了解决这个问题：**把每一笔出入金记下来，用数据告诉你真实情况，在你冲动的时候拦你一下。**

## 功能

### 记录管理
- 出入金记录增删改查，桌面端内联编辑，移动端卡片+Modal
- 按月分组折叠，不再被几十条记录淹没
- **多维度筛选**（月份、日期区间、金额区间、平台、资产类型、关键词）
- **筛选汇总条**：筛选后自动计算入金、出金、净盈亏、回本率
- Excel / JSON 导入导出（5 Sheet，中英文字段名兼容）

### 统计分析
- 总入金、总出金、净盈亏、回本比例一目了然
- 月度/周/年度盈亏统计 + 累计盈亏
- 平台维度统计 + 资产类型维度统计
- 月度趋势折线图（入金、出金、净盈亏、累计）
- 资产配置饼图（投入分布 / 净值分布）
- 周期对比卡片（当前周期 vs 上个周期 · 环比变化）
- 月度预算（进度条 + 超支警告）
- 大额交易提醒

### 行为分析 & 心理画像
- 分析你的入金行为模式：星期分布、金额区间、入金间隔
- 自动识别危险信号：追单倾向、大额冲动、加码回本、连续入金
- 生成心理标签和针对性建议

### FOMO 防控
- **冷静提醒**：入金时自动检测危险模式（间隔太短、频率偏高、超出预算、金额异常），弹窗让你停下来想一想
- **月度预算**：设定每月入金上限，进度条实时显示
- **入金理由**：每次入金都可以写下理由——"为什么要入这笔？"

### 体验
- **深色 / 浅色模式**切换，自动跟随系统
- **桌面端 + 平板 + 手机端**全适配
- 手机端卡片式列表、底部 Tab 栏、浮动添加按钮
- **PWA 支持**：添加到主屏幕，像 App 一样使用，离线可用
- **90+ 条投资大师语录**（利弗莫尔、巴菲特、索罗斯、达里奥等），每次打开随机提醒

### 数据安全 & 云同步
- 数据存在浏览器 localStorage，完全离线可用
- 自动快照（最多 10 份）+ 手动快照 + 一键恢复
- **GitHub Gist 云同步**：免费、安全、带版本历史，多端自动同步
  - 只需一个 GitHub Personal Access Token（仅 gist 权限）
  - 数据加密存储在你的私有 Gist 中
  - 每次同步自动保留版本，可随时回溯到历史版本
  - 启动时自动静默拉取，无需手动操作

## 使用方式

### 最简单：直接打开
下载 `index.html`，浏览器打开即可使用。无需安装，无需服务器。

### 手机使用
1. 部署到 GitHub Pages 或 Netlify
2. 手机浏览器打开链接
3. Safari 点「分享 → 添加到主屏幕」/ Chrome 点「添加到主屏幕」
4. 从主屏幕打开，全屏使用，和原生 App 一样

### 多端同步
1. 在 GitHub [Developer settings → Tokens (classic)](https://github.com/settings/tokens/new) 创建一个 Token（Note 随意、Expiration 选 No expiration、只勾选 `gist` 权限）
2. 在其中一台设备上打开 FlowLedger → 同步设置 → 填入 Token → 点击「上传云端」
3. 在其他设备上填入同一 Token → 点击「拉取云端」
4. 之后每次打开自动同步，也可手动点击「一键同步」双向合并
