## 为什么做这个？

投资的人或多或少都经历过这样的循环：**亏了 → 不甘心 → 再充钱 → 又亏了 → 继续充**。

很多人到最后都不知道自己到底往里面扔了多少钱，只有一个模糊的感觉："好像亏了不少"。而这种模糊感恰恰是最危险的——因为你不知道具体数字，就不会真正警觉。

FlowLedger 就是为了解决这个问题：**把每一笔出入金记下来，用数据告诉你真实情况，在你冲动的时候拦你一下。**

不是交易工具，不是行情软件，就是一个**记账本 + 心理医生**。

## 功能

### 📝 记录管理
- 出入金记录增删改查，支持内联编辑
- 按月分组折叠，不再被几十条记录淹没
- 标签系统：给每笔记录标记 `定投`、`补仓`、`FOMO` 等行为标签，支持筛选和标签盈亏统计
- **多维度筛选**（月份、日期区间、金额区间、交易所、关键词等），命中月份单独展示
- **筛选汇总条**：筛选后自动计算这段时间 / 某交易所的入金、出金、净盈亏、回本率
- Excel / JSON 导入导出（导入前预览、重复记录检测、合并或覆盖确认，文件名带时间戳）
- 导入历史：每次导入形成批次记录，支持一键撤销合并导入或恢复覆盖导入前账本

### 📊 统计分析
- 总入金、总出金、净盈亏、回本比例一目了然
- 月度/周/年度盈亏统计 + 累计盈亏
- 交易所维度统计
- 月度趋势折线图（入金、出金、净盈亏、累计）
- 周期对比卡片（当前周期 vs 上个周期 · 环比变化）
- 大额交易提醒

### 🧠 行为分析 & 心理画像
- 分析你的入金行为模式：星期分布、金额区间、入金间隔
- 自动识别危险信号：追单倾向、大额冲动、加码回本、连续入金
- 生成心理标签和针对性建议

### ⚠️ FOMO 防控
- **冷静提醒**：入金时自动检测危险模式（间隔太短、本周太频繁、超出预算、金额异常），弹窗让你停 3 秒想一想
- **月度预算**：设定每月入金上限，进度条实时显示，快到上限变红
- **入金理由**：每次入金强制你写下理由——"为什么要入这笔？"，让你正视自己的动机

### 🎨 体验
- **白天 / 夜间模式**切换，自动跟随系统
- **桌面端 + 平板 + 手机端**全适配
- 手机端卡片式列表、底部 Tab 栏、浮动添加按钮
- 手机端记录详情：点开记录可查看折合 CNY、同平台/同资产历史汇总和相关记录
- **PWA 支持**：添加到主屏幕，像 App 一样使用，离线可用
- **80 条交易大师语录**（利弗莫尔、索罗斯、巴菲特等），每次打开随机提醒

### 💾 数据安全 & 云同步
- 数据存在浏览器 localStorage，完全离线可用
- 自动快照（最多 10 份）+ 手动快照 + 一键恢复
- 导入前自动识别新增、完全重复、疑似重复和无效行，默认安全合并
- 导入历史保留最近 20 次，可撤销误导入
- **GitHub Gist 云同步**：免费、安全、带版本历史，多端自动同步
  - 只需一个 GitHub Personal Access Token（仅 gist 权限）
  - 数据存储在你的私有 Gist 中，每次同步自动保留版本
  - 启动时自动静默拉取，无需手动操作
  - 支持双向合并同步（本地优先去重）

## 使用方式

### 最简单：直接打开
下载 `index.html`，浏览器打开即可使用。无需安装，无需服务器。

### 在线访问
部署在 GitHub Pages：**[https://你的用户名.github.io/FlowLedger/]()**

### 多端同步
1. 在 GitHub [Developer settings → Tokens (classic)](https://github.com/settings/tokens/new) 创建一个 Token（Note 随意、Expiration 选 No expiration、只勾选 `gist` 权限）
2. 在其中一台设备上打开 FlowLedger → 同步设置 → 填入 Token → 点击「上传云端」
3. 在其他设备上填入同一 Token → 点击「拉取云端」→ 自动发现你的 Gist
4. 之后每次打开自动同步，也可手动点击「一键同步」双向合并

### 手机使用
1. 手机浏览器打开上面的链接
2. Safari 点「分享 → 添加到主屏幕」/ Chrome 点「添加到主屏幕」
3. 从主屏幕打开，全屏使用，和原生 App 一样
