# 投记 · 个人投资记账与资产追踪

投记是一款本地优先的个人投资记账与资产追踪工具。它记录每一笔出入金，追踪持仓实时市值，把“投入 + 持仓 + 已落袋”合并成真实净值和真实收益。

它不是行情软件，也不替你下单。投记更像一个安静的投资账本：让你知道自己投了多少、取出了多少、手里还值多少，以及哪些操作可能是情绪驱动。

## 核心功能

### 记录管理
- 出入金记录增删改查，支持桌面端表格编辑和手机端详情编辑
- 多资产类型：大 A、美股、港股、加密货币、基金、黄金、期货、其他
- 多货币：CNY、USD、HKD、USDT，并支持汇率折合 CNY
- 标签系统：可给记录标记 `定投`、`补仓`、`FOMO` 等行为标签
- 按年份分组折叠展示，长账本也能快速浏览

### 持仓追踪
- 持仓管理：记录标的、份额、成本价、币种
- 支持市场筛选和中文名/代码搜索
- 持仓实时估值，展示成本、市值、盈亏和真实收益率
- 行情滚动条展示自选市场价格

### 统计分析
- 总入金、总出金、净盈亏、回本比例
- 持仓市值、真实收益、真实收益率
- 周、月、年度盈亏统计和累计盈亏
- 交易所、资产类型、标签维度统计
- 资产配置甜甜圈图和月度趋势图
- 可自定义数据看板展示模块

### 行为复盘
- 入金冷静提醒：检测频繁投入、大额投入等风险
- 投入行为分析：星期分布、金额区间、入金间隔、连续入金
- 心理画像、复盘建议、复盘清单和周期笔记
- 中英文界面切换和新手引导

### 数据安全与 GitHub 同步
- 数据默认保存在浏览器 localStorage，离线可用
- Excel 导入导出、JSON 备份导入
- 导入前预览，自动识别新增、完全重复、疑似重复、无效行
- 合并导入和覆盖导入都记录导入历史，可一键撤销
- 自动快照和手动快照，方便恢复误操作
- GitHub Gist 同步：免费、带版本历史、适合手机和电脑多端使用

## 使用方式

### 直接打开
下载 `index.html`，用浏览器打开即可使用。无需安装依赖，也无需服务器。

### 静态部署
可以部署到 GitHub Pages、Netlify、Vercel 或任意静态网页服务器。

### 手机使用
1. 用手机浏览器打开部署后的页面
2. Safari 选择“分享 -> 添加到主屏幕”，Chrome 选择“添加到主屏幕”
3. 从主屏幕打开后，就可以像轻量 App 一样使用

## GitHub Gist 同步

投记的同步不是把数据放进公开仓库，而是放进你自己的 Private Gist。简单理解：

手机把账本上传到你的私有 Gist，电脑再从同一个 Gist 拉下来。两边之后会按记录更新时间合并，尽量避免互相覆盖。

使用步骤：

1. 打开 GitHub 的 Token 页面：[Generate new token (classic)](https://github.com/settings/tokens/new)
2. Note 随便写，比如 `touji-sync`
3. Expiration 可以选 No expiration
4. 权限只勾选 `gist`
5. 生成 Token 后复制
6. 打开投记 -> 同步设置 -> 粘贴 Token
7. 第一台设备点“上传云端”
8. 第二台设备填同一个 Token 后点“拉取云端”

注意：Token 只保存在你自己的浏览器 localStorage 里，不会写进仓库。

## 产品理念

投记的核心是：用数据代替感觉，用记录减少冲动。

它优先保证个人数据可控、可备份、可恢复；同步能力作为可选增强，而不是强制把数据交给某个平台。
