# 流水时间与逐笔换汇设计

## 目标

让每条流水可以记录具体到分钟的发生时间，并让外币入金同时保留人民币支付金额、到账币种、到账数量和该笔实际成交汇率。实时汇率只用于辅助填写，用户手填值始终优先。

## 数据模型

旧字段保持不变，避免破坏统计、持仓和同步：

```js
{
  date: "2026-08-08",
  time: "15:36",
  amount: 74.183976,       // 到账数量，兼容原有外币金额语义
  currency: "USDT",       // 到账币种
  rate: 6.74,              // 1 USDT = 6.74 CNY
  sourceAmount: 500,       // 实际支付金额
  sourceCurrency: "CNY",
  targetAmount: 74.183976,
  targetCurrency: "USDT",
  fxRate: 6.74
}
```

旧记录没有 `time` 或换汇字段时继续沿用原有 `amount * rate` 计算。新换汇入金优先使用 `sourceAmount` 统计人民币本金，避免到账数量舍入造成总入金误差。

## 录入交互

- CNY 入金继续填写单一金额。
- USD、HKD、USDT 入金显示“支付金额（CNY）”“实际汇率”和自动计算的“到账数量”。
- “拉取当前汇率”把参考值写入汇率输入框，用户可以继续修改。
- 每次保存都会固化该笔汇率；未来拉取新汇率不会修改历史记录。
- 日期和时间分开输入，默认当前日期和当前分钟。

## 展示与兼容

- 流水按 `date + time` 倒序；无时间的旧记录按当天 `00:00` 处理。
- 换汇流水显示人民币支付金额、到账数量和实际汇率。
- Excel 增加时间、支付金额/币种、到账金额/币种、实际汇率列。
- JSON 和 PostgreSQL 同步使用现有 JSON payload，新增字段无需数据库迁移。
