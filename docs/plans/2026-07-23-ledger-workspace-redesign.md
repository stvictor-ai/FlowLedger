# 流水账本工作台设计

## 目标

把电脑端流水页从“后台表格”改成阅读优先的财富账本。用户可以快速扫描历史记录，通过年份、月份、类型和关键词定位记录，点击后在同一页面右侧查看与编辑。

## 视觉方向

- 安静、精致的编辑型财富账本
- 雾白与深墨绿作为主体，金色只用于选择和强调
- 默认不显示输入框边框，避免页面处处处于编辑状态
- 月份作为版式分隔，不再使用卡片套表格
- 金额、日期和类型形成稳定列，方便纵向比较

## 交互

1. 顶部保留核心筛选，更多筛选按需展开。
2. 筛选结果以紧凑汇总条展示。
3. 月份分组默认展开，只展示命中的记录。
4. 点击记录后，右侧出现详情编辑面板。
5. 保存、关闭或删除后回到账本阅读状态。
6. 手机端沿用现有记录卡片与底部编辑弹窗。

## 数据与兼容性

- 不修改流水和持仓数据模型。
- 复用现有 `editingEntry`、`saveEditEntry` 和删除逻辑。
- 买入、卖出的受保护字段继续禁止直接修改。
- 保留现有筛选、同步、导入和统计计算。

## 验证

- 桌面端检查列表、筛选、详情打开、保存和删除确认。
- 适配 1280、1440 和宽屏布局。
- 手机端确认仍使用原有卡片和底部弹窗。
- 运行 JavaScript 语法检查和复盘引擎测试。
